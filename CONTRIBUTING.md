# Contributing and Learning Guidelines

This repository documents my 180-day journey toward becoming an AI/ML Engineer.

## Repository Purpose

This repository contains daily learning notes, Python exercises, problem-solving practice, experiments, and progress updates.

Polished, standalone projects are maintained separately in my AI engineering portfolio repository.

## Learning Workflow

For each study day:

1. Record the topics learned.
2. Write code and solve exercises independently.
3. Explain important concepts in my own words.
4. Include examples and edge cases.
5. Test the code where appropriate.
6. Record challenges, mistakes, and lessons learned.
7. Update the relevant README or progress tracker.

## Code Quality

- Use meaningful variable and function names.
- Prefer readable, simple Python code.
- Follow PEP 8 conventions where practical.
- Add comments when they clarify non-obvious logic.
- Write tests for functions when appropriate.
- Do not commit API keys, passwords, or private information.

## Folder Organization

Keep daily work in the relevant topic folder. Avoid duplicating the same files across multiple folders.

## Learning Philosophy

Consistency matters more than speed. Exercises should reflect genuine understanding, and solutions should be revisited when a concept is unclear.
