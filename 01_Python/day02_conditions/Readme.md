## Challenge

* **Building a Nested/Complex Decision Matrix:** Combining multiple conditions using logical operators (`and`, `or`, `not`) to accurately evaluate edge cases, such as determining leap years or parsing file types with overlapping rules.
* **Implementing Structural Pattern Matching:** Transitioning from long `if-elif-else` chains to the more pythonic `match-case` statements for cleaner, more readable code structure.

## Key Learning

I use conditionals when my program needs to make a decision.

## Difficulties

* **Handling Edge Cases and Logical Precedence:** Resolving subtle logical bugs when multiple conditions overlap, ensuring that specific criteria are checked in the correct sequence before broader defaults take over.
* **Input Sanitization and Formatting:** Dealing with case sensitivity, trailing spaces, or invalid data types when reading user inputs before applying conditional evaluations.

## What I Learned

* **Writing Clean Pythonic Conditionals:** How to write concise control flows using conditional expressions (ternary operators) and nested logic without sacrificing readability.
* **Control Flow Mastery:** Understanding how `if`, `elif`, and `else` blocks route program execution sequentially and how `match-case` simplifies multi-branched routing.
